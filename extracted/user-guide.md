# NoteWise user guide

## Sign in

Open `index.html` in a modern browser. Use **student@demo.com** / **learn123**. This is a local demonstration gate, not secure authentication.

## Find and tag notes

- Search for words in a note title, its content, or its selected tags.
- Select a topic in the left sidebar to filter the library. Select it again, or use **Clear filter**, to remove that filter.
- Select a note to read it and view its selected topics.
- Click a topic chip to add or remove that topic. Multiple tags are supported. The edited selection is saved in this browser and takes precedence over future suggestions.
- Choose **Reset to suggestions** only when you want to replace your edits with the keyword baseline's current suggestions.
- Choose **New note**, enter a title and content, then save. Review the resulting topic suggestions; correct them as needed.
- **Sign out** returns to the demo login. Local notes remain in this browser.

## Accessibility and privacy

Controls are keyboard-operable buttons and form fields with labels; status messages are announced with live regions. Keep note content non-sensitive: local storage is not encrypted, this prototype does not implement user accounts, and the demo password is visible in its source.
